ФИЗКУЛЬТУРА БЕЗ БАРЬЕРОВ — ИНТЕРАКТИВНЫЙ САЙТ

СОДЕРЖИМОЕ
index.html — главная страница и тесты
style.css — оформление
script.js — логика тестов, проверки и отчёта
questions.js — 120 вопросов с вариантами и ключами

ПРОВЕРКА БЕЗ ИНТЕРНЕТА
Откройте index.html двойным нажатием в браузере.
Тесты работают и без интернета.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Создайте аккаунт на github.com, если его ещё нет.
2. Создайте новый публичный репозиторий, например fizkultura-testy.
3. Загрузите в корень репозитория все четыре файла: index.html, style.css, script.js, questions.js.
4. В Settings → Pages → Build and deployment выберите Deploy from a branch, branch main, папку /(root), нажмите Save.
5. После публикации появится ссылка вида https://USERNAME.github.io/fizkultura-testy/
6. Отдельные темы доступны по ссылкам:
   https://USERNAME.github.io/fizkultura-testy/index.html?test=1
   ... до ?test=6
   Замените USERNAME и название репозитория на свои.
7. Для обновления вопросов замените questions.js в репозитории. Ссылки сохранятся, пока репозиторий и публикация существуют.

ВАЖНО
— Публикация на GitHub Pages делает сайт доступным всем, у кого есть ссылка.
— Проверка проводится на устройстве студента. Централизованного сбора ответов нет.
— Студент может скачать TXT-отчёт и отправить преподавателю.
— Это не защищённая экзаменационная система: ключи доступны в коде сайта,
  а TXT-отчёт можно изменить. Для официального оценивания требуется контроль преподавателя.
— Не размещайте в репозитории списки студентов и персональные данные.
— Рекомендуется предварительно проверить все вопросы и ключи преподавателем.
